# 模块清单（谁拉起、谁看着）

> 规矩：**长驻模块一律挂壳或监工**，不许从工具调用里随手起——工具调用结束会被带走（判断 160/177）。
> 判据：`ps -eo pid,ppid,cmd` 里，长驻模块的 PPID 只能是「壳」或「1」，出现别的父进程就是临时进程，当成会随时消失。

## 一、长驻（有循环、要一直跑）

| 脚本 | 干什么 | 谁拉起 | 谁补位 |
|---|---|---|---|
| `监工.py` | 每 5 秒点名其余常驻；处理 `/tmp/dsh-restart.req` | 壳 | 壳下挂 |
| `壳下挂.py` | 断点接续（写开机票）+ 每 60 秒点名含监工在内的常驻 | 壳 | 监工 |
| `通道看门狗.py` | 每 15 秒探云端/本地，3 分钟 10 次失败切通道 | 壳 | 监工 |
| `虚拟引擎.py --watch` | 热备 + 引擎兜底（有壳时只记录不拉） | 壳 | 监工 |
| `虚拟对话.py --watch` | 对话镜像 | 壳 | 监工 |
| `eigenflux … watch --dispatch` | 网络收件箱派发 | 壳 | 监工 |

## 二、按需（跑一次就退，不进常驻名单）

| 脚本 | 什么时候跑 |
|---|---|
| `采集体检.py` | 每小时自我唤醒的第一件事 |
| `老对话管家.py` | 每 6 小时那轮 |
| `语气体检.py` / `人味.py` | 收工链、写完长文之后 |
| `通知.py` | 所有通知的唯一出口（安静时段自动暂存） |
| `来件.py` | 收工链（只写异常与要拍板的） |
| `断点.py` / `断点广播.py` | 开工收尾、重启前 |
| `工具体检.py` | 壳每次拉起引擎后、以及手工核查 |
| `小模型.py` | 主意识要它做改写时（拒接判断类） |
| `换模型.py` | 换本地模型时（拉 → 实测 → 改配置 → 删旧） |

## 三、脚本与配置的归属

- **壳**：`/usr/local/bin/dsh`（容器入口，监工 + 启停 + 端口仲裁 + stop 标记时效）。
- **引擎**：DSH web（3080），它死了壳拉起。
- **代码型插件**（profile 里 20 个包）：不是进程，随引擎加载，不进本清单。
